# Peaceful World — Public GitHub Hub

This repository supports the public GitHub presence of **Peaceful World**, an international nonprofit association working on peace education, nonviolence, human dignity, de-escalation and peace literacy.

## Why this repository exists

Most active product repositories are private while they are under development. This public hub provides a stable layer for public priorities, contribution opportunities, organization-wide community files, public operational documentation, volunteer task discovery and links to official support and transparency information.
