# Security Policy

Peaceful World welcomes responsible reports about security vulnerabilities in our websites, applications and repositories.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a suspected security vulnerability.

Email **hello@peaceful-world.org** with the subject line `SECURITY` and include, where possible:

- the affected repository, page, application or URL;
- a clear description of the issue and its potential impact;
- steps to reproduce it;
- screenshots, logs or a minimal proof of concept if they are helpful;
- any suggested mitigation.

Please do not include passwords, private keys, access tokens or other third-party secrets in a report.

We aim to acknowledge security reports within seven days and will prioritize issues affecting live public services, user data, authentication, releases or software supply-chain integrity.

## Responsible disclosure

Please give us reasonable time to investigate and address a vulnerability before publishing technical details. Good-faith security research intended to help protect Peaceful World and its users is welcome.

This policy is an organization-wide default and may be supplemented by repository-specific security guidance where needed.
