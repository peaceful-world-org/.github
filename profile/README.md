# Peaceful World

Peace education for everyone.

Peaceful World is an international nonprofit association developing open, multilingual education around nonviolence, human dignity, de-escalation and peace literacy.

## Projects

- [5](https://github.com/peaceful-world-org/5) — a five-minute secular peace practice.
- [True Cost of War](https://github.com/peaceful-world-org/true-cost-of-war) — tools for making the costs of war easier to understand.
- [Atlas of Peace](https://github.com/peaceful-world-org/atlas-of-peace) — an evolving peace-knowledge project.
- [Website Lab](https://github.com/peaceful-world-org/website-lab) — experimental web interfaces and public-facing prototypes.

## Contribute

We welcome thoughtful contributions in software, design, research, accessibility, localization, data, documentation and quality assurance.
